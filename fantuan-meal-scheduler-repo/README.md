# 饭团 · fantuan-meal-scheduler 🍙

> 适时介入式 AI 用餐调度 WorkBuddy Skill —— 不是一问一答，而是状态感知 + 时机触发：AI 记住你的课表、忌口、口味、预算，在合适时机主动上门，把三餐从头到尾安排明白。

**赛道**：创意开发赛道「用餐｜把饭点安排明白」

---

## ✨ 核心特性

- **四类适时介入**：T1 时间卡点（三餐自动链式触发）｜T2 风险预警（库存售罄换菜、课表变动调计划）｜T3 纠结收束（含盲盒模式）｜T4 多人拼局实时同步
- **显式加权评分模型**（可复现、可解释）：口味 30% + 历史 20% + 点赞 20% + 目标 15% + 排队 10% + 价格 5%
- **跨窗口真实时联动**（BroadcastChannel）：用户端 ↔ 商家端 ↔ 室友窗口，订单状态与拼局方案实时回流
- **一次录入**：3 步向导（基础信息 → 课表 OCR 预填+人工确认含单双周 → 偏好测试），全程只问一次
- **数据闭环**：拍照 Ins 手账 → 点赞加权 → 次日推荐排首位 → 记账 + 健康周报
- **防骚扰护栏**：顺延一次即静默、忽略不重复、宁可不打扰
- **边界兜底**：预算不足放宽标注、忌口冲突明确标注（确定性代码，不依赖 LLM）

## 🚀 快速开始

**体验 Demo**：直接双击 `assets/fantuan-demo.html`，走完 3 步录入向导即可。推荐体验路径：

> 午餐自动卡点 → 锁定 → 控制台「🏪 新窗口打开商家端」+「帮我下单排队」看跨窗口实时联动 → 「库存不足」看预警 → 吃完拍照入手账 → 确认记账 → 「⚠️ 边界场景」看兜底 → 「📱 真机通知预览」

**安装为 WorkBuddy 技能**：将本仓库放入 `~/.workbuddy/skills/`（用户级）或 `.workbuddy/skills/`（项目级），重启会话后说"今天吃什么"即可触发。

## 🎬 3 分钟演示脚本（评委向）

录入（示例课表+确认制）→ 午餐卡点带图介入 → 锁定 → 商家端联动排队 → 库存预警换菜 → 拼局同步 → 拍照手账+记账 → 模拟第二天看点赞加权 → 健康周报 → 边界兜底 + 真机通知预览收尾。

## 🔧 二次开发

Demo 内四个核心配置区：

| 配置区         | 作用                                    |
| ----------- | ------------------------------------- |
| `DISH_POOL` | 菜池（早/午/晚，价格/窗口/主食/卖点）                 |
| `MEALS`     | 三餐话术与图标                               |
| `SIM_DATA`  | 模拟数据源（库存/课表变动/室友/排队）——真实环境替换为商家端与教务接口 |
| `SCORE_W`   | 评分权重（调整后推荐排序即时变化）                     |

真机迁移映射：拍照→`wx.createCameraContext`｜推送→小程序订阅消息 + 云函数 cron｜实时→云开发 watch｜支付→微信支付。

## 📝 已知边界

- 定时介入依赖页面驻留（真机方案：订阅消息 + 服务端 cron，Demo 内有通知样式预览）
- 课表 OCR 为演示预填（预填+确认制，错误不传导；生产建议接教务系统/ics）
- 库存/排队为模拟信号（SIM_DATA 单一数据源，换数据即接真）
